# ESAOG reference implementation and SOST experiments

Executable Semantic Agent Orchestration Graph (ESAOG): LLM proposes, the semantic layer
(OWL 2 + HermiT, SPARQL 1.1, SHACL, PROV-O) decides what executes; runtime state and
provenance drive local recomposition.

**Important deviation:** no LLM API was available, so every LLM call is served by
`SimLLM` (`src/esaog/simllm.py`), a seeded behavioural model, and tools are simulated
behind an MCP-style JSON-RPC server (`src/esaog/runtime.py`). Semantic-layer timings are
real; LLM/tool latencies, tokens and costs are simulated. Baselines B4–B8 are
mechanism-equivalent re-implementations, not the published systems.

## Layout
| Path | Content |
|---|---|
| `ontology/` | core upper ontology (O_G, O_C, O_W, O_R, O_P; PROV-O reuse), 3 domain modules, alignment module (SKOS links to AgentO; documented PROV-AGENT correspondence) |
| `shapes/` | SHACL workflow shapes (7) and registry shapes (A4) |
| `queries/` | SPARQL: A1 eligibility, reliability, COMPAAS-like, graph router, provenance completeness, failure trace |
| `prompts/` | prompt templates used by SimLLM (token counts are computed from them) |
| `benchmark/sost_benchmark.json` | 192 SOST instances (3 domains × 8 bases × N/L/H/I/P/F/R/C), declarative perturbations |
| `src/esaog/` | semantic store, reasoner, SimLLM, runtime + adapters (LangGraph, direct, MCP), methods (B0–B8, P, M1–M7), oracle |
| `scripts/` | `run_experiments.py`, `coverage.py`, `sensitivity.py`, `trace_example.py`, `analysis.py`, `fill_paper.py` |
| `results/raw/` | per-run `runs.jsonl`/`runs.csv`, sensitivity runs, coverage, manifests |
| `results/tables/`, `results/figures/` | generated LaTeX tables and PDF figures |
| `tests/` | unit tests (entailment, A1 vs oracle, SHACL, registration, adapter equivalence, URI continuity) |

## Reproduce
```bash
bash run_all.sh            # ~25 min on 8 cores; requires Java for HermiT
```
Environment: Python 3.12, `requirements.txt`. Real-LLM runs: implement the `SimLLM`
interface (`decompose`, `repair_decomposition`, `choose`) with an API client.

## Local models (Ollama)
All Ollama models live on the external drive: `~/.ollama/models` is a symlink to
`/Volumes/ExternalHDD/ollama_models`, so the standard Ollama app (port 11434) serves them.
Use the default host for new runs (`ESAOG_OLLAMA_HOST` unset, or `http://localhost:11434`); the
`scripts/run_real_llm_queue*.sh` files from the original experiment point at a temporary second
instance on port 11435 that no longer runs. The external drive must be mounted before starting Ollama.
Example:
  ../.venv/bin/python scripts/run_experiments.py --profile llm:ollama:qwen2.5:14b \
      --methods P,B1 --seeds 0 --workers 1 --out real_example
